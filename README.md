# Лабораторная работа по программированию

## Цель работы

Изучить способы представления данных в памяти компьютера, научиться выводить двоичное представление чисел и изменять отдельные биты средствами C++.

## Выполненные задания

### Задание 1

Реализован вывод основных типов данных C++:

- `bool`;
- `char`;
- `short int`;
- `int`;
- `long int`;
- `long long`;
- `float`;
- `double`;
- `long double`.

Для каждого типа выводится его размер в байтах и краткое описание.

### Задание 2

Для знакового и беззнакового целого числа выводится двоичное представление. У знакового числа отдельно отмечается бит знака.

Для просмотра битов значение копируется в беззнаковую переменную подходящего размера с помощью `memcpy`.

### Задание 3

Выводится двоичное представление типа `float` в формате IEEE 754:

```text
бит знака | биты порядка | биты мантиссы
```

Для `float` используется 1 бит знака, 8 бит порядка и 23 бита мантиссы.

### Задание 4

Выводится двоичное представление типа `double` в формате IEEE 754:

```text
бит знака | биты порядка | биты мантиссы
```

Для `double` используется 1 бит знака, 11 бит порядка и 52 бита мантиссы.

### Задание 5

Реализована работа с отдельными битами для разных типов данных. Пользователь может:

1. установить выбранный бит в `1`;
2. сбросить выбранный бит в `0`;
3. инвертировать выбранный бит.

Для целых типов, `float` и `double` используются битовые операции:

- `|` — установка бита;
- `&` — сброс бита;
- `^` — инверсия бита.

Для `long double` используется работа с массивом байтов, так как этот тип нельзя обрабатывать обычными операциями над целыми числами.

Пользовательский режим выбирается из главного меню. В нём можно отдельно запустить любое задание с 1 по 5; пустая строка завершает текущее меню или задание.

Отдельный демонстрационный режим без ввода пользователя показывает фиксированные примеры для заданий 2–4: положительное и отрицательное целые числа, обычные значения `float` и `double`, а также минимальные денормализованные значения этих типов. Задание 5 демонстрируется только в пользовательском режиме.

Для `long int` используется его фактический размер. Если на платформе этот тип занимает 8 байт, выводится 64 бита; если размер типа отличается, обработка выполняется без копирования за пределы буфера.

### Задание 6

Шестое задание находится в отдельном файле `task_6.cpp` и запускается отдельно от основной программы.

## Использованные функции

Для работы с представлением данных были выделены общие функции:

- `print_bits` — вывод битов числа;
- `change_bits` — изменение выбранного бита;
- `change_and_print` — изменение бита с выводом исходного и нового представления;
- `change_long_double_bits` — изменение битов типа `long double`.

## Рефакторинг

Общие функции работы с битами вынесены в отдельные файлы:

```text
bit_functions.h
bit_functions.cpp
```

В заголовочном файле находятся объявления функций и директива `#pragma once`, а их реализации находятся в `bit_functions.cpp`.

Файл `main.cpp` содержит задания, пользовательское меню и отдельный демонстрационный режим. Файл `task_6.cpp` оставлен отдельным.

При рефакторинге алгоритмы работы с битами не изменялись. Были убраны повторяющиеся функции и вынесен общий код вывода битов.

## Вывод

В ходе лабораторной работы были изучены способы хранения целых и вещественных чисел в памяти, структура IEEE 754, битовые операции и работа с отдельными битами. Также был выполнен рефакторинг программы с разделением общих функций по модулям.

## Сборка программы

Основную программу можно собрать командой:

```bash
g++ main.cpp bit_functions.cpp -o program
```

Шестое задание собирается отдельно:

```bash
g++ task_6.cpp -o task_6
```
