# Типы данных и их внутреннее представление в памяти

Лабораторная работа по C++, посвящённая размерам типов данных, их битовому представлению и изменению отдельных битов с помощью побитовых операций.

## О работе

Программа демонстрирует, сколько памяти занимают основные типы C++, как целые и вещественные числа представлены в памяти и как можно изменить выбранный бит.

## Реализованные задания

- **Задание 1.** Вывод размеров типов данных в байтах: `bool`, `char`, `short int`, `int`, `long int`, `long long`, `float`, `double`, `long double`.
- **Задание 2.** Вывод двоичного представления знакового и беззнакового целого числа.
- **Задание 3.** Вывод битового представления `float` с разделением на знак, порядок и мантиссу.
- **Задание 4.** Вывод битового представления `double` с разделением на знак, порядок и мантиссу.
- **Задание 5.** Изменение выбранного бита: установка в `1`, сброс в `0` или инверсия.

## Используемые средства

- C++
- Стандартная библиотека C++: `<iostream>`, `<iomanip>`, `<string>`, `<cstdint>` и `<cstring>`
- Компилятор с поддержкой C++, например `g++`

## Сборка и запуск

Если файл с программой называется `main.cpp`, соберите его командой:

```bash
g++ main.cpp -o lab
```

Запуск в Windows:

```powershell
.\lab.exe
```

В Linux или macOS:

```bash
./lab
```

Если задание 5 находится в отдельном файле `task_5.cpp` и содержит собственную функцию `main()`, его можно собрать отдельно:

```bash
g++ task_5.cpp -o task5
```

Запуск в Windows:

```powershell
.\task5.exe
```

> Если проект будет разделён на несколько `.cpp`-файлов, передайте все необходимые файлы компилятору одной командой.

## Побитовые операции

- `&` — побитовое И;
- `|` — побитовое ИЛИ;
- `^` — исключающее ИЛИ;
- `<<` — сдвиг влево;
- `>>` — сдвиг вправо.

Для копирования объектного представления значения используется `memcpy`.

## Примечание

Размеры типов зависят от платформы и компилятора. Результаты `sizeof` относятся к среде, в которой собрана программа.
